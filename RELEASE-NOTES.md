# Portl Beta — build 3.6.0

Five improvements make the real desktop app easier to customize:

- **Quick Edit:** Select a preview widget to see name, visibility, opacity and its useful everyday controls immediately. Detailed configuration remains in All widget settings.
- **Starter layouts:** Layouts → Explore starter layouts previews Minimal, Gaming, Study and Creator. Choose atmosphere, display and widgets, then create a new Space while retaining previous layouts and personal content.
- **Theme composer:** Coordinated atmosphere, wallpaper preview, accent, glass opacity and roundness in one place, with a live Clock card. Individual widget overrides remain intact.
- **Editing feedback:** Actual calculated snap guides, measured neighboring gaps, clearer selection/resize handles and Escape recovery. Existing gesture-grouped Undo/Redo is preserved.
- **First-run setup:** A three-step style/widget/display flow creates a usable Space; existing users can run it from Settings. Compact dialogs keep actions accessible while their body scrolls.

Existing seventeen native widgets, named Spaces, personal writing, light/dark collections, system telemetry, desktop controls and updater remain available. Settings format 6, original profile folder, app ID and existing update feed are unchanged. Starter previews do not mutate the active layout, and OS wallpaper apply remains separate.

Use **Portl-3.6.0-Setup.exe** for Windows x64 installation and automatic updates. Existing installed users can check in Settings and choose Restart to update after download. Portable updates remain manual. Windows builds remain unsigned; no new Mac/Linux runtime release is included.

See VERIFICATION.md for test results and practical limits. The Studio screenshot is from the actual packaged application using a sanitized test profile.
