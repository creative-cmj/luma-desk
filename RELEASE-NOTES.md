# Portl Beta — build 3.5.0

A redesigned, interactive Desktop Studio for arranging your real desktop widgets.

- Navy glass surfaces, lavender/cyan accents, refined typography, clearer navigation and an original flowing-ribbon wallpaper.
- Functional Widgets/Themes/Layouts inspector tabs, synchronized selection/properties and clearer empty states.
- Improved monitor-aware preview Fit, real aspect ratio, pointer dragging/resizing and grouped Undo/Redo.
- Adding a widget targets the selected monitor, selects the new instance and opens its properties.
- Refined Clock and Quick Launch cards, with configurable launcher columns and existing personal shortcuts preserved.
- New System widget: actual CPU, RAM and system-drive usage, bounded activity graph, explicit unavailable states. Sampling runs only while needed and metrics are never saved. Small telemetry-only messages avoid broadcasting the complete settings view on every sample.
- Seventeen working widget types, existing themes, Spaces, native desktop controls, command palette, Focus and Peek retained.
- Save feedback reflects pending/failure states; retry preserves the previous file and exact personal writing.
- Explicit settings format 6 migration preserves byte-identical original format 1–5 backups before writing. Existing app ID, profile path, feed and storage keys are unchanged.

Use Portl-3.5.0-Setup.exe for Windows x64 automatic updates. Existing installed users can check in Settings and choose Restart to update after download. Portable updates remain manual. Windows builds are unsigned. The older separate Mac preview is unchanged.

See VERIFICATION.md for tested behavior and limits, and SHA256SUMS.txt for asset integrity. The Desktop screenshot is captured from the actual packaged application using a sanitized test profile, not a static app mockup.
