# Portl Beta

Formerly Luma Desk. Local desktop widgets, personal Spaces and a colorful Desktop Studio. Current Windows Beta build: **3.4.11**.

[Windows download](https://github.com/creative-cmj/luma-desk/releases/tag/v3.4.11) · [Release details](RELEASE-NOTES.md) · [Verification](VERIFICATION.md)

Portl has a new violet-to-cyan portal logo across the app, startup, tray and Windows installer. Your existing Luma Desk data folder, app identity and update feed are retained. Notes, Spaces, settings and old preset exports remain compatible.

Sixteen local widgets, coordinated light/dark collections, native desktop editing, snapping/alignment guides, keyboard controls, Undo/Redo, shared-content Spaces, per-widget styling, searchable command palette, optional toolbar, Peek and Focus Mode. No app account, analytics or cloud sync.

## Install and update

Use **Portl-3.4.11-Setup.exe** for Windows x64. Existing installed Luma/Portl users can check for updates in Settings, then choose Restart to update after download. Background downloads also install when you choose Quit; closing the panel keeps the tray app running. Keep one copy running at a time. The portable package requires manual updates. Windows builds are unsigned.

The established profile folder remains `%APPDATA%\Luma Desk`; its contents are not renamed. Profile format remains 5. Close the app before backing up the complete folder. Do not post profiles publicly: they may contain personal writing and paths.

The separate [Mac 2.6 preview](https://github.com/creative-cmj/luma-desk/releases/tag/v2.6.0) remains unchanged. New Mac icon assets do not constitute a tested Mac release. No native Linux package is included.

Internal Beta build numbers keep increasing for update compatibility. The first finished public release is planned as Portl 1.0. This repository contains release binaries and public documentation, not application source. It is an independent project and does not bundle the Hyprland compositor.
