# Portl Beta

A local desktop customization studio with seventeen widgets, personal Spaces and coordinated light/dark themes. Current Windows Beta build: **3.5.0**.

[Windows download](https://github.com/creative-cmj/luma-desk/releases/tag/v3.5.0) · [Release details](RELEASE-NOTES.md) · [Verification](VERIFICATION.md)

The redesigned Desktop Studio has navy glass surfaces, lavender/cyan accents, an original ribbon wallpaper, a tabbed Widgets/Themes/Layouts inspector and a monitor-aware canvas. Configure your own launcher shortcuts, arrange native widgets, and use real CPU/RAM/system-drive readings in the new System widget. No app account, cloud sync or analytics.

## Install and update

Use **Portl-3.5.0-Setup.exe** for Windows x64 installation and automatic updates. Existing installed Luma/Portl users can check in Settings, then choose Restart to update after download. Ready background downloads also install when you choose Quit Portl; closing the panel keeps the tray app running. Keep one copy running at a time. Portable updates are manual. Windows binaries are unsigned.

The established app identity, update feed and original `%APPDATA%\Luma Desk` profile location are retained. Settings/export format is now 6. Versions 1–5 migrate forward with an untouched original backup required before writing. Notes, tasks, Spaces and old preset exports are preserved. Close the app before backing up the complete folder; restore the original backup before manually downgrading. Profiles can contain personal writing and paths and should not be posted publicly.

Previewing a wallpaper does not apply it to Windows. Native desktop attachment can use a clearly reported fallback depending on the Windows environment. First CPU readings and unsupported storage values show unavailable states.

The separate [Mac 2.6 preview](https://github.com/creative-cmj/luma-desk/releases/tag/v2.6.0) is unchanged. No new Mac or Linux runtime release is included. Internal Beta build numbers keep increasing for update compatibility; the first finished public release is planned as Portl 1.0. This independent project does not bundle the Hyprland compositor. This repository contains release binaries and public documentation, not application source.
